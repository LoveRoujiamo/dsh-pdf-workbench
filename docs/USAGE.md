# PDF 全能工具台 · 使用说明

> 版本 1.1.2 · 本机处理 · 结果保留 24 小时

## 一、打开工作台

安装后，左侧最窄的那条侧栏会出现 **PDF 工具台** 图标（深蓝色文档图标，排在会话面板之下）。点击即进入工作台；再次点击其它面板图标可切走，工作台状态会保留在页面里。

进入后是三栏布局：

```
┌──────────┬────────────────────────────┬──────────────┐
│ 功能导航  │ 上传 → 参数 → 开始处理       │ 结果预览/下载 │
│ 4 大类    │ （首页为功能卡片墙）          │              │
└──────────┴────────────────────────────┴──────────────┘
```

左栏顶部有搜索框，可直接搜功能名；点左上「返回首页」回到卡片墙。左右两栏都可折叠；窗口变窄时三栏会自动收窄列宽，需要时可手动折叠侧栏。

## 二、通用五步流程

所有功能都走同一套流程，学会一个就会全部：

1. **选功能** —— 左栏点选，或首页卡片。
2. **上传文件** —— 点击或把文件拖进上传区；PDF 合并支持拖拽调整顺序，其它多文件功能按添加顺序处理。上传区会显示每个文件的名称与体积，可单独移除。
3. **设参数** —— 中栏参数面板随功能变化，带默认值；必填项没填时「开始处理」是禁用的，并且会说明缺什么。
4. **开始处理** —— 进度条会显示阶段文案（例如「正在处理第 3 页」）；随时可以取消。
5. **取结果** —— 右栏出现结果卡片：PDF 可以逐页预览、翻页；图片直接预览；文本可直接阅读。点「下载」保存单个文件，或点「全部下载」（批量任务优先给打包好的 zip）。

处理失败时右栏会给出一条错误说明和建议动作，下方「重试」会带着同样的文件与参数重跑。加密文件会提示先到「PDF 解密」移除保护，扫描件则会提示先跑 OCR。

若一次处理只能部分成功（例如某一页没检测到可裁剪内容），右栏会额外列出「需要注意」的条目，结果文件仍然照常生成。

处理中左侧导航会暂时禁用，避免误切功能导致正在跑的任务被丢弃。

## 三、控制输出体积（不用再跑两遍）

以前是「先合并/转 PDF，再单独压缩一次」；现在同一个任务里就能一步到位：

**合并 PDF / 多格式转 PDF / 批量统一页面尺寸** 的参数面板底部都有：

- **限制输出体积（超出自动压缩）** —— 打开开关
- **目标大小 (MB)** —— 例如填 10，表示每个输出 PDF 不超过 10 MB

处理时会自动压缩到达标，只**降采样图片**，文字与矢量线条保持原样（依然清晰、可搜索、可复制）。
压不到目标时不会假装成功：会输出能压到的最小结果，并在结果区提示「无法压到目标体积，最小 X MB」。

**PDF 压缩** 工具本身也新增了「压到指定体积」模式：不想按低/中/高档位猜，直接填目标 MB 即可。

结果卡片会直接显示压缩前后体积，例如：

> 合并结果.pdf · 8.9 MB · **已压缩 12.4 MB → 8.9 MB**

目标没达到时徽章会变成红色的「未达到目标体积」。

> 说明：纯文字型 PDF 的可压缩空间本来就有限（没有图片可降采样），这种情况请改用「拆分」或降低目标值。

## 三、功能速查

### 格式转换中心

| 功能 | 说明 |
|---|---|
| PDF 转 Word | 输出可编辑 `.docx`；「流式排版」便于编辑，「按原位置排版」更接近原始版面 |
| PDF 转 Excel | 自动识别表格，按表格或按页拆成多个 Sheet |
| PDF 转 PPT | 每页一张幻灯片；可选「页面截图（保真）」或「文字+图片（可编辑）」 |
| PDF 转图片 | PNG / JPG，可调 DPI 与质量，输出压缩包 |
| PDF 转纯文本 | 提取全文，可选保留分页标记 |
| 多格式转 PDF | Word / Excel / PPT / 图片 / TXT 批量转 PDF，可合并为一个文件 |

### 文档编辑工具箱 · 基础操作

- **合并**：多份 PDF 合成一份，可先拖拽调整顺序，可选为每个文件生成书签。
- **拆分**：三种模式——按页码范围（`1-3,4-6,7-` 每段一个文件）、每 N 页拆一份、按文件体积阈值拆。
- **压缩**：低（画质优先）/ 中（均衡）/ 高（体积最小）。文字默认保持矢量，压缩后依然可以搜索和选中。
- **加密**：设置打开密码与权限密码，可分别限制打印、修改、复制、批注。
- **解密**：输入正确密码后去掉保护。
- **旋转 / 删除页面 / 提取页面 / 插入空白页**：都支持指定页码，`1-3,5` 这种写法通用。

### 文档编辑工具箱 · 页面排版（本次新增重点）

**页面尺寸调整（单文档）**

1. 上传一份 PDF。
2. 选纸张：A3 / A4 / A5 / B5 / Letter / Legal / Tabloid，或选「自定义尺寸」后填宽高（单位可选毫米 / 英寸 / 像素）。
3. 选适配模式：
   - **等比缩放适配**（默认）：整页等比缩放到纸张内，内容居中、四周补白。不会变形，也不会丢失内容。
   - **居中裁剪填充**：等比放大到铺满纸张，超出部分居中裁掉。适合消除白边但会裁掉边缘。
   - **拉伸铺满**：按宽高各自缩放，完全铺满，可能有轻微变形。
4. 可选：强制竖向 / 横向、指定处理页码范围（范围外的页面原样保留）、留白边距、背景色。
5. 默认勾选「保留书签 / 链接 / 批注 / 表单字段」，处理后文档结构不丢。

处理走矢量重建，文字与线条保持矢量，不会因为改纸张而变糊。

**批量统一页面尺寸（多文档）**

1. 一次拖入最多 20 份 PDF（单份 ≤ 100 MB，合计 ≤ 300 MB）。
2. 纸张规格与适配模式同「单文档」，一套规则应用到全部文件。
3. 点开始后，右栏显示总体进度、已完成 / 失败数量，以及逐文件状态列表。
4. 每个文件按原名独立输出，默认再打包一个 zip；也可以单独下载某个文件。
5. **单个文件失败不会中断整体**：处理结束后失败项单独列出，点该项的「重试」只重跑这一个文件，已成功的不会重复处理。

**白边智能裁剪**

- **智能自动裁剪**：逐页识别有效内容边界（可调「白边判定灵敏度」，数值越大越保守），自动切除四周白边。
- **手动精确裁剪**：自己填上 / 下 / 左 / 右边距（毫米）。
- **统一所有页面裁剪尺寸**（默认开启）：所有页面裁成同一个尺寸，避免处理后每页大小不一，最适合打印。
- **安全留白阈值**：在识别到的内容边界外额外保留的距离，防止把贴边的文字或图像误裁掉。
- 支持指定页码范围，只优化文档局部。

**添加页码**：页眉 / 页脚 × 左 / 中 / 右六个位置，四种格式（`1`、`1 / 12`、`第 n 页`、`- 1 -`），可设字体、字号、起始页码、距边距离。

### 内容提取与增强

- **OCR 文字识别**：扫描件 → 带文字层的 PDF（文字可选中、可搜索）或纯文本。支持中文 + 英文。
- **图片批量提取**：导出文档里所有内嵌图片，按页序命名；可过滤小图、可转换格式。
- **目录结构提取**：导出 Markdown / 缩进文本 / JSON 大纲；原文没有书签时，可按字号推断标题层级。
- **水印添加**：文字或图片水印，可设透明度、旋转角度、页面中央或平铺（含对角斜铺）与重复密度。

### AI 智能处理

AI 功能使用「设置 → 模型」里当前选中的模型，无需额外填 API Key。

- **智能摘要**：结构化 / 一句话 / 详尽三种风格，输出核心观点、章节大纲、关键数据、结论建议，并带页码出处。
- **内容问答**：针对文档自由提问，回答带（第 N 页）引用；同一份文档可以连续追问，历史会自动带上。
- **全文翻译**：中英日韩德法西俄互译，输出双语对照或纯译文，可导出 PDF / DOCX / TXT。
- **纠错润色**：输出 Markdown 表格（页码 / 原文片段 / 问题类型 / 修改建议），并附润色后全文。
- **信息结构化提取**：用自然语言写清洗要求（例：提取合同甲方、乙方、签署日期、金额、有效期），输出 Excel / Word / Markdown 表格。

长文档会自动分段解析再合并，不会因为超长而失败。

## 四、限制与注意事项

| 项目 | 限制 |
|---|---|
| 单文件大小 | ≤ **100 MB** |
| 单次文件数 | ≤ **20 个** |
| 单次上传总量 | ≤ **300 MB**（超出请分批） |
| 结果保留 | **24 小时**，之后原件与结果自动删除 |
| 支持输入 | `.pdf`；转 PDF 另支持 `.doc/.docx/.xls/.xlsx/.ppt/.pptx/.png/.jpg/.jpeg/.webp/.bmp/.tif/.tiff/.txt/.md` |
| 支持输出 | `.pdf` `.docx` `.xlsx` `.pptx` `.png` `.jpg` `.txt` `.md` `.json` `.zip` |
| OCR 语言 | 中文 + 英文 |
| 单次翻译页数 | ≤ **80 页**，超出请分段 |
| Office 转 PDF | 依赖本机 LibreOffice；未安装时该功能会明确提示不可用 |

其他注意事项：

- 加密的 PDF 需要先在参数里填入正确密码，否则会提示无法打开。
- 扫描版 PDF 没有文字层，AI 功能会提示先跑 OCR；这是正确的行为，不是故障。
- 批量任务里任何一个文件失败都不会影响其他文件，失败项可单独重试。
- 页面尺寸调整对「范围内的页面」重建，范围外页面原样保留；重建页上的批注如无法迁移，会在结果里以警告形式说明。
- 文件只写入本机临时目录；只有 AI 功能会把**提取出的文字**发送给当前配置的模型服务，PDF 二进制文件本身不上传。

## 五、故障排查

| 现象 | 处理 |
|---|---|
| 面板显示「出错了」+ 重新加载 | 点「重新加载」；仍失败请刷新页面，并确认插件在 设置 → 插件 中已启用 |
| 「没有可用的模型路由」 | 到 设置 → 模型 选择一个可用模型 |
| 「PDF 引擎没有返回结果」 | 检查文件是否为有效 PDF；损坏文件建议先用其它工具修复 |
| 处理很久没有进展 | 点取消后重试；超大文件建议先拆分 |
| 结果下载失败 | 结果可能已超过 24 小时保留期，请重新处理 |

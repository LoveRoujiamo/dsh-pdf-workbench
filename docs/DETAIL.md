# PDF 全能工具台

在 DSH 里打开左侧面板栏的「PDF 工具台」图标即可进入。工作台自成一页：左侧功能导航、中间操作区、右侧结果预览，全部处理都在本机完成。

## 能做什么

**格式转换**：PDF ⇄ Word / Excel / PPT / 图片 / 纯文本；Word、Excel、PPT、图片、TXT 批量转 PDF。

**文档编辑**：合并（可拖拽排序）、拆分（按页码段 / 每 N 页 / 按体积）、压缩（低中高三档，或直接指定目标体积）、加密与解密、页面旋转、删除、提取、插入空白页、添加页码。

**输出体积控制**：合并、多格式转 PDF、批量统一尺寸都可以在同一个任务里限制输出体积——超出目标自动压缩，文字保持矢量；结果区会显示压缩前后的体积。

**页面排版**：

- **页面尺寸调整（单文档）**——A3/A4/A5/B5/Letter/Legal/Tabloid 预设或自定义宽高（mm/in/px），等比缩放、居中裁剪、拉伸铺满三种适配模式，可强制方向、指定页码范围、设置留白与背景色。走矢量重建，文字与线条不会糊；书签、文档信息、页内链接会一并迁移。
- **批量统一页面尺寸（多文档）**——一次最多 20 份 PDF 用同一套规则统一规格，每个文件独立输出并打包；单个文件失败不影响其他文件，结果列表里可以只重试失败项。
- **白边智能裁剪**——自动识别内容边界后裁掉四周白边，也可手动指定四边边距；支持「统一所有页面裁剪尺寸」、安全留白阈值与页码范围。

**内容提取**：OCR 文字识别（扫描件生成可复制文字的 PDF 或纯文本）、内嵌图片批量提取、目录结构提取（Markdown / 文本 / JSON）、文字与图片水印（透明度、旋转、平铺密度）。

**AI 智能处理**（走「设置 → 模型」里当前选中的模型）：结构化摘要、基于原文的问答（带页码引用）、全文翻译（双语对照或纯译文，可导出 PDF / DOCX / TXT）、纠错润色报告、按指定字段做信息结构化提取并导出表格。长文档会自动分段解析。

## 限制

- 单文件 ≤ 100 MB，单次 ≤ 20 个文件，单次上传总量 ≤ 300 MB。
- 结果文件与上传原件保留 24 小时，之后自动删除。
- OCR 语言为中文 + 英文。
- 单次翻译最多处理 80 页，超出部分需分段处理。
- Word / Excel / PPT 转 PDF 使用本机 LibreOffice；未安装时该功能会明确提示。

## 数据

文件只写入本机临时目录，不出本机；只有 AI 功能会把提取出的文字发送给当前配置的模型服务。
